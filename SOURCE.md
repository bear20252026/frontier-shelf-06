# Source code — Frontier VI

The catalogue cards are one HTML file; the source they describe is in this repository.

- `source/three/examples/` — the 109 local three.js example pages for this volume, with the shared examples assets, jsm modules, fonts and textures.
- `source/three/build/`, `source/three/src/`, `source/three/LICENSE` — the matching three.js build, engine source and licence.
- `source/vendor/` — `BenjaminAster/CSS-Minecraft`, `CodingTrain/Machine-Learning`, `KhronosGroup/WebGLDeveloperTools`, `KhronosGroup/glTF`, `dli/paint`, `evanw/lightgl.js`, `mrdoob/codevember-2026`, `mrdoob/slop-newyork`, `saharan/works`

Three.js cards open `./source/three/examples/<file>`; the catalogue's live/upstream links remain on the card for provenance. Source is fetched from the single forks under [bear20252026](https://github.com/bear20252026), not from 650 per-card clones. The source tree is added by the repository's `Vendor source code` workflow.
